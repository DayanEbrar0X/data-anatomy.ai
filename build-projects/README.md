# Build Projects

Big, end-to-end projects: the kind you would put in a portfolio or ship at work. Each project lives in its own
folder with a full README, an architecture overview, and a video series that builds it part by part.

Smaller, single-topic builds (like [API to Parquet](../data-engineering/build-lab-01-api-to-parquet)) live in their
domain folder instead.

No projects here yet. New ones are posted on [YouTube](https://www.youtube.com/@datanatomyai) · [TikTok](https://www.tiktok.com/@datanatomy.ai) · [Instagram](https://www.instagram.com/datanatomy.ai) first.
