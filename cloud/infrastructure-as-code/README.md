# Infrastructure as code

Defining servers, networks, databases and permissions in code instead of clicking through a console, so every
environment can be reviewed, versioned and rebuilt the same way.

- **Terraform:** providers, resources, state, modules, plan and apply
- **Terragrunt:** keeping Terraform DRY across many environments and accounts
